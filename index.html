Айракты — Аудит Яндекс

Импорт реального CSV Яндекс с разделителем ;, проверка найденных колонок, расчет сумм по водителям, документам и категориям. Данные не уходят на сервер и хранятся только в браузере.

Поддерживаются колонки: Дата; ID водителя; Водитель; ID категории; Категория; Сумма; Документ; Инициатор; Комментарий. Если в старом файле есть «Событие» вместо «Документ» или «Исполнитель» вместо «Водитель», они тоже будут распознаны.
